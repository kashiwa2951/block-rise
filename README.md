# BLOCK RISE

**せり上がる床**と**崩れ落ちるブロック**という 2 つのルールで連鎖を組み立てる、
9 × 22 マスの落ちものパズルです。ブラウザだけで動きます。

ビルド不要。`index.html` をダブルクリックするだけで遊べます。

---

## 遊び方

### 基本

上から降ってくるブロックを積み、**横一列をそろえると消えます**。

### ピースは 9 種類

4 マスのピース 7 種に加えて、**3 マスのピースが 2 種**混ざります。

```
  まっすぐ        かぎ形
   ███            █
                  ██
```

3 マスピースは小回りがきくので、**せり上がりが作った 1〜2 マスの穴を埋める**のに向いています。
4 マスピースだけでは届かない隙間を片づける役です。

9 種を 1 巡ぶんずつシャッフルして配るので、どのピースも同じ頻度で必ず回ってきます
（9 個引くあいだに、必ず 1 個ずつ全種類が来ます）。

### 独自ルール 1 : 土台がせり上がる

一定時間ごとに、盤面の下から穴あきのブロック行がせり上がってきます。

- 盤面上部の **RISE バー**が残り時間。空になるとせり上がりが発生します。
- レベルが上がるほど間隔が短くなります（レベル 1 で 32 秒 → 最短 11 秒）。
- 残り 4 秒で警告音が鳴り、盤面の下端に**次にせり上がる行の予告**（赤い帯）が出ます。
  帯が途切れている列がそのまま穴になるので、そこを狙って積むと有利です。
- **穴の位置は 2〜3 行つづけて同じ列に空きます。**穴が縦につながるので、
  その列にピースを落とし込むだけで、せり上がった行をまとめて消せます。
  縦向きの I ピースを差し込めば一気に 2〜3 行片付きます。
- ブロックが天井に届いた状態でせり上がるとゲームオーバーです。

### 独自ルール 2 : 最後に置いたブロックが崩れて落ちる

ライン消去のあと、**最後に置いたピースの残ったマスは形を崩してバラバラに真下へ落ちます。**

```
 ① O ピースを置いて 1 列そろう        ② その行が消える           ③ 残りが形を崩して落ちる
    ┌──────────┐              ┌──────────┐          ┌──────────┐
    │▓▓▓▓▓▓▓██·│                │▓▓▓▓▓▓▓██·│            │▓▓▓▓▓▓▓·█·│
    │▓▓▓▓▓▓▓██▓│ ← そろった      │          │            │          │
    │▓▓▓▓▓▓▓·▓·│                │▓▓▓▓▓▓▓·▓·│            │▓▓▓▓▓▓▓█▓·│ ← 左だけ落ちて…
    └──────────┘              └──────────┘          └──────────┘   もう一列そろう＝連鎖！
```

- 落ちる距離は**列ごとにバラバラ**です。下が空いている列だけ深く落ち、
  下が詰まっている列はその場に残るので、ピースの形が崩れます。
- 落ちた結果また列がそろえば **連鎖（CHAIN）** となり、スコア倍率が上がります
  （2 連鎖 ×1.5、3 連鎖 ×2.0、以降 +0.5）。
- 「わざと穴を残して上をふさぎ、あとで一気に埋めて連鎖させる」のがこのゲームのコツです。

### スコア

まとめ消しほど伸びが大きくなる配点です。

| 要素 | 得点 |
|---|---|
| 1 ライン | 120 × レベル |
| 2 ライン | 340 × レベル |
| 3 ライン | 700 × レベル |
| 4 ライン | 1400 × レベル |
| 連鎖 | 上記に倍率（2 連鎖 ×1.5、3 連鎖 ×2.0 …） |
| コンボ | 60 × コンボ数 × レベル |
| ソフトドロップ | 2 / マス |
| ハードドロップ | 4 / マス |

12 ライン消すごとにレベルが 1 上がり、落下速度とせり上がり速度が上がります。
ハイスコアはブラウザに保存されます。

## 操作

### キーボード

| キー | 動作 |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | 移動 |
| <kbd>↓</kbd> | ソフトドロップ |
| <kbd>↑</kbd> / <kbd>X</kbd> | 右回転 |
| <kbd>Z</kbd> | 左回転 |
| <kbd>Space</kbd> | ハードドロップ |
| <kbd>C</kbd> / <kbd>Shift</kbd> | ホールド |
| <kbd>P</kbd> / <kbd>Esc</kbd> | 一時停止 |
| <kbd>R</kbd> | リスタート |
| <kbd>M</kbd> | サウンド切り替え |

### スマホ・タブレット

操作は**盤面の上だけでなく、盤面の左右の余白でも受け付けます**。
盤面の外を触れば、指でブロックが隠れません。

- **タップ** → 回転
- **左右にドラッグ** → 移動（指を戻せばピースも戻ります。小さなブレでは動きません）
- **下へ素早くフリック** → ハードドロップ
- **下へゆっくりドラッグ** → ソフトドロップ
- **上へスワイプ** → ホールド
- 画面下のボタンでも同じ操作ができます（▼ は 1 回押すと 1 マス、押しっぱなしで連続）

## 動かし方

### そのまま開く

`index.html` をダブルクリックするだけです。ビルドもインストールも不要で、
インターネット接続もいりません。

### GitHub Pages で公開する

このリポジトリはビルド不要の静的サイトなので、そのまま公開できます。

1. GitHub のリポジトリページを開く
2. **Settings** → 左メニューの **Pages**
3. **Source** で **Deploy from a branch** を選ぶ
4. **Branch** を `main` / `(root)` にして **Save**
5. 1〜2 分待つと `https://kashiwa2951.github.io/block-rise/` で公開されます

公開後は、スマホのブラウザで URL を開けばそのまま遊べます。
ホーム画面に追加しておくとアプリのように起動できます。

## 構成

ビルドツールも外部ライブラリも使っていません。素の HTML / CSS / JavaScript のみです。

```
index.html        画面の構造
css/style.css     見た目・レスポンシブ対応
js/config.js      チューニング値（盤面サイズ・速度・スコア・配色）
js/pieces.js      ピース9種（4マス7種+3マス2種）の定義、回転と壁ぎわ補正、袋方式ランダマイザ
js/board.js       盤面データ、ライン消去、せり上がり、★崩れ落ち処理
js/audio.js       Web Audio API による効果音（音声ファイル不要）
js/input.js       キーボード（DAS/ARR）とタッチ操作
js/render.js      Canvas 描画とアニメーション
js/game.js        ゲームループと状態機械
```

### 難易度などの調整

`js/config.js` の数値を書き換えるだけで調整できます。

| 項目 | 意味 |
|---|---|
| `RISE_BASE` / `RISE_STEP` / `RISE_MIN` | せり上がり間隔（初期値／レベルごとの短縮／最短） |
| `RISE_HOLE_MIN` / `RISE_HOLE_MAX` | せり上がる行に空く穴の数 |
| `RISE_SAME_HOLE_MIN` / `RISE_SAME_HOLE_MAX` | 同じ穴の位置を続ける行数（大きいほど消しやすい） |
| `GRAVITY_BASE` / `GRAVITY_FACTOR` | ピースの落下速度とレベルごとの加速 |
| `SOFT_DROP_INTERVAL` | ソフトドロップ中の落下間隔（秒／1マス）。大きいほどゆっくり |
| `DRAG_STEP_RATIO` / `DRAG_STEP_MIN` | 横ドラッグの感度。大きいほど鈍くなる |
| `DRAG_DEADZONE_RATIO` / `DRAG_DEADZONE_MIN` | 指のブレで動かないようにする遊び |
| `LINES_PER_LEVEL` | レベルアップに必要なライン数 |
| `FALL_PER_CELL` | 崩れ落ちるブロックのアニメーション速度 |
| `TOUCH_GUTTER_MIN` / `TOUCH_GUTTER_MAX` / `TOUCH_GUTTER_RATIO` | 盤面左右に確保するタッチ操作用の余白 |
| `COLORS` | ブロックの配色 |

ピースの出現頻度は `js/pieces.js` の `BAG_SET` で変えられます。
ここに並べたものが 1 巡ぶんとして配られるので、同じ種類を 2 回書けばその種類だけ出やすくなります。
3 マスピース（`'D'` と `'V'`）を減らせば難しく、増やせばやさしくなります。

### 開発用デバッグフック

ブラウザのコンソールから `BB.debug` で盤面を直接操作できます。

```js
BB.debug.setRiseInterval(9999);                  // せり上がりを止める
BB.debug.setBoard(['######...','######..#','######.##']);  // 盤面を作る（下端そろえ・9列）
BB.debug.spawn('O', 7, 0);                       // ピースを指定位置に出す
BB.debug.drop();                                 // ハードドロップ
BB.debug.dump();                                 // 現在の盤面を文字列配列で取得
BB.debug.forceRise();                            // せり上がりを即時発動
BB.debug.state();                                // スコアやフェーズを確認
```
