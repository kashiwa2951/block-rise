遊び方

ルール

  • 上から降ってくるブロックを積み、横一列をそろえると消えます。
  • 土台が時間とともにせり上がります。盤面上部のバーが空になるとせり上がり発生。レベルが上がるほど間隔が短くなります。
  • 最後に置いたブロックの落下：列が消えたあと、そのピースの残ったマスは形が崩れてバラバラに真下へ落ち、下の隙間を埋めます。埋めた結果また列がそろえば連鎖！
  • ブロックが天井に届くとゲームオーバーです。

キーボード操作

  • ←→ 移動
  • ↓ ソフトドロップ
  • ↑ / X 右回転
  • Z 左回転
  • Space ハードドロップ
  • C / Shift ホールド
  • P 一時停止 / R リスタート

スマホ操作

  • 操作は盤面の左右の余白でも受け付けます。盤面の外を触れば、 指でブロックが隠れません。
  • タップ → 回転 ／ 左右にドラッグ → 移動
  • 下へ素早くフリック → ハードドロップ ／ ゆっくり下ドラッグ → ソフトドロップ
  • 上へスワイプ → ホールド ／ 画面下のボタンでも操作できます
